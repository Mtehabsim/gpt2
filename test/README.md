# Tests

`test_environment.py` is a smoke test to verify that Python, PyTorch, and the local module import work. **It does not validate GPT-2.**

As you progress through ARENA 1.1, write tests for numerical behavior, tensor shapes, masking, residual connections, and later reference-model parity.

The original ARENA `tests.py` and `solutions.py` are intentionally **not** copied into this repository. Keep an independent ARENA checkout if you want to run their original exercises.
